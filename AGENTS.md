# Repository instructions

Project documentation belongs under [`docs/`](docs/), with this file and the root [`README.md`](README.md) retained as short entrypoints. Agent working directories are ignored; curated plans and agent task reports live under [`docs/superpowers/`](docs/superpowers/).

## MIS 2024 reports

When the user asks for an **MIS 2024 report** — an MIS endurance report, an
IEM24 Murphy report, or a simulated-vs-measured MIS lap comparison — produce it
in the format fixed by
[docs/standards/mis-2024-report-standard.md](docs/standards/mis-2024-report-standard.md).

That standard defines the required sections, tables, figures, conventions,
mandatory disclosures, and the delivery checklist. Read it before writing the
report, and copy its template rather than inventing a structure.

The reference implementation is
[docs/validation/iem24-murphy/report.md](docs/validation/iem24-murphy/report.md),
generated by `tools/reports/compare_iem24_murphy_stint.py`. `tests/test_mis_report_standard.py`
checks every `docs/validation/**/report.md` against the standard, so a report
that drifts out of format fails the test suite.

## Where things live

| Path | Contents |
|---|---|
| `src/simplified_vehicle_models/` | The library: XML compiler, models, solvers |
| `models/` | XML model graph: vehicles, tires, aero, powertrains, tracks |
| `tools/` | Runnable studies, report generators, and data import/export |
| `docs/standards/` | Binding standards for deliverables |
| `docs/validation/` | Validation reports and their generated data |
| `docs/dev/` | Developer documentation |
| `tests/` | The unit and regression suite |

## Hard runtime limit

Every run—including tests, map builds, benchmarks, and simulations—must be
terminated at **30 minutes wall-clock time (1,800 seconds)** unless the user
explicitly approves a longer run beforehand. Enforce this with a process-level
watchdog covering the entire run and its child processes; a tool wait timeout
or cooperative solver budget is not sufficient. Use smaller scoped runs when
necessary. Never silently restart timed-out work to evade this limit.

## Commands

```bash
# Full test suite.
PYTHONPATH=src python3 -m unittest discover -s tests -q

# Compile a formulation and inspect the resolved model.
PYTHONPATH=src python3 -c "from simplified_vehicle_models.compiler.compile import compile_formulation; print(compile_formulation('models/formulations/murphy_point_mass.xml').model)"
```

Some tools need CasADi (planar optimal control) and the bundled wheels under
`/tmp/casadi_pkgs`; the tools state their own `PYTHONPATH` in their docstrings or
in the report that cites them.
