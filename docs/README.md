# docs

Data kept with the project that is not code: model-data provenance, validation artifacts, and documentation examples.

## Subdirectories

| Directory | Purpose |
|---|---|
| `dev/` | Home of the example input files used by the documentation tests. |
| `model-data/` | Provenance record of the exported model data in `models/data`. |
| `validation/` | Generated validation artifacts: summaries, tables and figures written by the report tools. |
