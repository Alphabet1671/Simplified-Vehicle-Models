## Task 13 regression status

The Task 13 broad scoped yaw suite initially ran under a 180 s process-group watchdog with **188 tests, 4 failures, 2 errors** (exit 1, 23.638 s). The deterministic causes were under-attested `vehicle_configuration_hashes` in comparator fixtures, which rejected preflight before intended assertions, and legacy replay stubs lacking optional `initial_state_overrides` (and `plant_variation`) attributes. The fixtures now carry strict-valid nonempty path→SHA-256 attestations while deliberately malformed/missing test cases remain intact; replay uses `getattr(..., None)` only for those optional attributes, preserving CLI validation when present. The exact scoped suite then passed: **188 tests in 20.272 s**, exit 0, under the same 180 s process-group watchdog. The physical-window functional suite remains **2 tests in 3.716 s** under a 600 s process-group watchdog. The complete repository invocation was run exactly once under the required 1,800 s watchdog and timed out with exit 124; it was not rerun. The repo-wide suite is therefore **not green**. Exact command/result is recorded in the ignored [Task 13 report](../../../.superpowers/sdd/2026-10-26-yaw-lap-suite-methodology-closure/task-13-report.md).

## Parked Important: root-source `//` path identity key

The suite accepts a `//`-prefixed filesystem source-path key in the run-contract provenance hash mapping. This edge case is parked as Important, not treated as a verified portability guarantee. The accepted key retains its literal spelling and can represent a root/double-slash path form whose meaning depends on platform/runtime path normalization; current runs use canonical absolute worktree paths and do not validate semantic equivalence across spellings. Cost: a copied or reconstructed contract that normalizes this key differently can lose source-hash lookup/identity compatibility and become inconclusive; blindly normalizing risks conflating distinct path namespaces. Keep this in final-deferred/known-limitations; do not silently rewrite historical manifests.
