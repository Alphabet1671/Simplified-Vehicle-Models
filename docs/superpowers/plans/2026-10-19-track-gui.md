# Track GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A PyQt6 program, `tools/track_gui/`, that designs open track courses from sections and builds closed tracks from MAT telemetry, and saves them as track models that `load_track` reads.

**Architecture:**
- A Qt-free core (`design.py`, `export.py`, `closed.py`) and a thin `qt/` layer, as in `tools/sim_gui/`.
- The GUI wraps `tools/tracks/open_course.py` and `tools/tracks/build_closed_track.py`. It does not copy their logic.
- A shared package, `tools/gui_common/`, holds the file-safety helpers and `ProcessJob`. This plan owns the package. The vehicle plan and the animation plan depend on it.
- The plots are `QPainter` widgets. There is no matplotlib in the GUI.

**Tech Stack:** Python 3.12+, PyQt6 ≥ 6.5 (6.11.0 is installed), numpy, `unittest`, `xml.etree.ElementTree`. SciPy ≥ 1.11 (the `forward` extra) is optional and only for the closed-track tab.

**Spec:** `docs/superpowers/specs/2026-10-19-gui-wrappers-investigation.md`, sections 1, 4, 7 and 8.

## Global Constraints

- Change nothing in `src/`. Do not edit the files of the simulation GUI (`tools/sim_gui/`). Read-only imports from it are listed under Fixed Decisions.
- Only `qt/` modules, `app.py` and the Qt tests import PyQt6. Every other new module imports only the standard library, numpy and the repository.
- PyQt6 stays an optional extra: `gui = ["PyQt6>=6.5"]` is already in `pyproject.toml`. Do not change `pyproject.toml`.
- Make it cross-platform. Use `pathlib`, `sys.executable`, and `QProcess` or `subprocess` with argument lists. Never use a shell. Do not use POSIX-only calls such as signals, `fork` or `timeout`.
- Write files atomically: write `<name>.tmp`, then `os.replace`. Write JSON with `indent=2, sort_keys=True, allow_nan=False`.
- A GUI never writes into `models/` unless the user ticks a confirmation. It never overwrites an existing output without an explicit confirmation. Track exports use the overwrite checkbox plus a separate generated-file confirmation when needed; saving a design JSON asks before replacing any existing path.
- Write the docs in ASD-STE100 style: short sentences, one idea in each sentence.
- Run tests as `MPLCONFIGDIR=/tmp/mplcfg PYTHONPATH=src:. QT_QPA_PLATFORM=offscreen python3 -m unittest tests.<module> -v`. Qt tests skip when PyQt6 is not installed.
- Every Qt test that creates a window stubs `QMessageBox.question`, `warning` and `information` in `setUp` and restores them with `addCleanup`. An unstubbed modal dialog hangs the test run.
- Name each new tool file so that no other `tools/*/` folder holds a file of the same name. `tests/test_default_track.py` globs `tools/*/<name>` and expects one match.
- Run a time-limited command with a Python `subprocess.run(..., timeout=N)` wrapper. macOS has no `timeout` command.
- The default output folder is `tracks_out/` in the repository root. Add `/tracks_out/` to `.gitignore`.
- The closed-track tab needs SciPy. Without SciPy, the application still starts, the tab shows a message, and **Build** is off.
- The two changes to `tools/tracks/` are additive. A call with the old arguments must give the old output byte for byte.
- Do not change `tools/sim_gui/catalogue.py:tracks()`. It lists only `closed-xy-profile` tracks, so an open course made here does not appear in the simulation GUI. This is intended.

## Output Layout

An open course writes two files. The XML refers to the CSV by a relative name.

```text
tracks_out/
├── <file name>.csv      # distance, X north, Y east, curvature; one row per node
└── <file name>.xml      # type="track-model" subtype="open-xy-profile"
```

A closed track writes the same two names with `subtype="closed-xy-profile"`.

A design file is JSON with these keys: `schema`, `sections`, `maximum_spacing`, `start_heading`, `start_north`, `start_east`, `allow_curvature_jumps`, `jump_ramp_length`. Each section has `kind`, `name`, `length`, `radius`, `angle_deg`, `curvature`, `end_curvature` and `rate`.

```python
from __future__ import annotations

import os
import tempfile
from pathlib import Path

REPOSITORY_ROOT = Path(__file__).resolve().parents[2]


def child_environment() -> dict[str, str]:
    """Return the environment for a repository child process."""
    environment = dict(os.environ)
    environment["PYTHONPATH"] = os.pathsep.join(
        [str(REPOSITORY_ROOT / "src"), str(REPOSITORY_ROOT)]
    )
    environment.setdefault("MPLCONFIGDIR", str(Path(tempfile.gettempdir()) / "mplcfg"))
    return environment
```

```python
"""Safe file writing and the checks the three GUIs share."""
from __future__ import annotations

import json
import os
import re
from pathlib import Path
from typing import Any

from tools.gui_common import REPOSITORY_ROOT

#: The name rule of ``tools/model_data/generate_component_sweep.py``.
NAME_PATTERN = re.compile(r"[A-Za-z0-9_-]{1,40}")

_GENERATED = re.compile(r"<!--(?:(?!-->).)*?Generated by\s+(tools/[\w./-]+)", re.S)


def check_name(value: str, what: str = "name") -> str:
    """Return ``value`` when it is 1 to 40 letters, digits, ``_`` or ``-``."""
    if not NAME_PATTERN.fullmatch(value or ""):
        raise ValueError(f"{what} must be 1 to 40 characters of letters, digits, _ or -: {value!r}")
    return value


def atomic_write_text(path: Path, text: str) -> None:
    """Write ``text`` to ``path`` through a temporary file in the same folder."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    temporary = path.with_name(path.name + ".tmp")
    with open(temporary, "w", encoding="utf-8", newline="\n") as stream:
        stream.write(text)
    os.replace(temporary, path)


def atomic_write_json(path: Path, payload: Any) -> None:
    """Write JSON with the repository settings: sorted keys, no NaN."""
    atomic_write_text(path, json.dumps(payload, indent=2, sort_keys=True, allow_nan=False) + "\n")


def is_inside(path: Path, root: Path) -> bool:
    """Return True when ``path`` is ``root`` or lies below it (links resolved)."""
    try:
        Path(path).resolve().relative_to(Path(root).resolve())
    except ValueError:
        return False
    return True


def generated_by(path: Path) -> str | None:
    """Return the generator named in a ``Generated by tools/...`` XML comment, or None."""
    try:
        text = Path(path).read_text(encoding="utf-8")
    except (OSError, UnicodeDecodeError):
        return None
    match = _GENERATED.search(text)
    return match.group(1).rstrip(".") if match else None


def protected_directory_problem(directory: Path, *, allow_models: bool) -> str | None:
    """Return a message when ``directory`` is inside ``models/`` without permission.

    ``models/sweeps/`` is exempt: it is git-ignored and the catalogue skips it.
    """
    models = REPOSITORY_ROOT / "models"
    if is_inside(directory, models / "sweeps"):
        return None
    if is_inside(directory, models) and not allow_models:
        return (f"{directory} is inside models/. Many tests pin the hashes of the files "
                f"there, so writing needs an explicit confirmation")
    return None
```

```python
    from PyQt6.QtWidgets import QApplication

def run_job(arguments, *, timeout=None, cancel_after_ms=None, wait_ms=20000):
    job = ProcessJob()
    lines, result = [], []
    loop = QEventLoop()
    job.line.connect(lines.append)
    job.finished.connect(lambda code, state: (result.append((code, state)), loop.quit()))
    job.start(arguments, timeout_seconds=timeout)
    if cancel_after_ms is not None:
        QTimer.singleShot(cancel_after_ms, job.cancel)
    QTimer.singleShot(wait_ms, loop.quit)
    loop.exec()
    return job, lines, result
```

```python
"""Run one repository child process and report its output line by line."""
from __future__ import annotations

import sys
from pathlib import Path

from PyQt6.QtCore import QObject, QProcess, QTimer, pyqtSignal

from tools.gui_common import REPOSITORY_ROOT, child_environment


class ProcessJob(QObject):
    """One ``QProcess`` with merged output, a timeout and a safe cancel.

    Signals: ``line(str)`` for each output line, ``finished(int, str)`` once with the exit
    code and a state word (``"done"``, ``"cancelled"``, ``"timed_out"`` or ``"failed_to_start"``).
    """

    line = pyqtSignal(str)
    finished = pyqtSignal(int, str)

    def __init__(self, parent=None) -> None:
        super().__init__(parent)
        self._process: QProcess | None = None
        self._buffer = ""
        self._state = "done"
        self._timer = QTimer(self)
        self._timer.setSingleShot(True)
        self._timer.timeout.connect(self._on_timeout)

    def running(self) -> bool:
        return self._process is not None

    def start(self, arguments: list[str], *, timeout_seconds: float | None = None,
              program: str | None = None) -> None:
        """Start ``program`` (default: this Python) with ``arguments`` from the repository root."""
        if self._process is not None:
            raise RuntimeError("a job is already running")
        process = QProcess(self)
        process.setProcessChannelMode(QProcess.ProcessChannelMode.MergedChannels)
        process.setWorkingDirectory(str(REPOSITORY_ROOT))
        environment = child_environment()
        from PyQt6.QtCore import QProcessEnvironment
        qt_environment = QProcessEnvironment()
        for key, value in environment.items():
            qt_environment.insert(key, value)
        process.setProcessEnvironment(qt_environment)
        process.readyReadStandardOutput.connect(self._read)
        process.finished.connect(self._on_finished)
        process.errorOccurred.connect(self._on_error)
        self._process, self._buffer, self._state = process, "", "done"
        process.start(program or sys.executable, list(arguments))
        if timeout_seconds:
            self._timer.start(int(timeout_seconds * 1000))

    def cancel(self) -> None:
        if self._process is not None and self._state == "done":
            self._state = "cancelled"
            self._process.kill()

    def _on_timeout(self) -> None:
        if self._process is not None and self._state == "done":
            self._state = "timed_out"
            self._process.kill()

    def _read(self) -> None:
        if self._process is None:
            return
        self._buffer += bytes(self._process.readAllStandardOutput()).decode("utf-8", "replace")
        # A progress writer may end lines with a carriage return, so split on both.
        pieces = self._buffer.replace("\r\n", "\n").replace("\r", "\n").split("\n")
        self._buffer = pieces.pop()
        for piece in pieces:
            self.line.emit(piece)

    def _on_error(self, error) -> None:
        if error == QProcess.ProcessError.FailedToStart and self._process is not None:
            self._state = "failed_to_start"
            self._finish(-1)

    def _on_finished(self, code: int, _status) -> None:
        self._read()
        self._finish(code)

    def _finish(self, code: int) -> None:
        process, state = self._process, self._state
        if process is None:
            return
        self._timer.stop()
        if self._buffer:
            self.line.emit(self._buffer)
        self._process, self._buffer = None, ""
        process.deleteLater()
        self.finished.emit(code, state)


def python_command(script: Path, *arguments: str) -> list[str]:
    """Return the argument list that runs a repository script under this interpreter."""
    return [str(script), *arguments]
```

```python
"""An editable open-course design: a section list and the build settings."""
from __future__ import annotations

import json
import math
from dataclasses import dataclass, field, replace
from typing import Any

from tools.tracks import build_fsae_dynamic_tracks as fsae
from tools.tracks.open_course import (OpenCourse, Section, arc, arc_by_angle, build_course,
                                      straight, transition)

KINDS = ("straight", "arc", "arc-angle", "clothoid")

#: Largest course the GUI builds. A longer course would make the preview slow.
MAXIMUM_LENGTH = 50_000.0


@dataclass(frozen=True, slots=True)
class SectionSpec:
    """One row of the section table.

    ``straight`` uses ``length``. ``arc`` uses ``length`` and ``curvature`` (right turn positive).
    ``arc-angle`` uses ``radius`` and ``angle_deg`` (right turn positive). ``clothoid`` uses
    ``curvature`` (start), ``end_curvature`` and ``rate`` (largest d(curvature)/ds in 1/m^2).
    """

    kind: str = "straight"
    name: str = ""
    length: float = 10.0
    radius: float = 10.0
    angle_deg: float = 90.0
    curvature: float = 0.0
    end_curvature: float = 0.0
    rate: float = 0.05

    def to_section(self) -> Section:
        name = self.name or self.kind
        if self.kind == "straight":
            return straight(self.length, name)
        if self.kind == "arc":
            return arc(self.length, self.curvature, name)
        if self.kind == "arc-angle":
            return arc_by_angle(self.radius, math.radians(self.angle_deg), name)
        if self.kind == "clothoid":
            return transition(self.curvature, self.end_curvature, self.rate, name)
        raise ValueError(f"unknown section kind {self.kind!r}; use one of {', '.join(KINDS)}")


@dataclass(frozen=True, slots=True)
class CourseDesign:
    """Sections plus the build settings of ``build_course``."""

    sections: tuple[SectionSpec, ...] = ()
    maximum_spacing: float = 0.25
    start_heading: float = 0.0
    start_north: float = 0.0
    start_east: float = 0.0
    allow_curvature_jumps: bool = False
    jump_ramp_length: float = 0.05

    def build(self) -> OpenCourse:
        """Build the course. Raise ``ValueError`` with a message the user can act on."""
        if not self.sections:
            raise ValueError("the course has no sections")
        if not (math.isfinite(self.maximum_spacing) and self.maximum_spacing > 0.0):
            raise ValueError("the node spacing must be positive")
        built = []
        for index, spec in enumerate(self.sections, start=1):
            try:
                built.append(spec.to_section())
            except ValueError as error:
                raise ValueError(f"section {index} ({spec.name or spec.kind}): {error}") from error
        if sum(section.length for section in built) > MAXIMUM_LENGTH:
            raise ValueError(f"the course is longer than {MAXIMUM_LENGTH:g} m")
        return build_course(
            built,
            maximum_spacing=self.maximum_spacing,
            start_heading=self.start_heading,
            start_north=self.start_north,
            start_east=self.start_east,
            allow_curvature_jumps=self.allow_curvature_jumps,
            jump_ramp_length=self.jump_ramp_length,
        )

    def with_sections(self, sections) -> "CourseDesign":
        return replace(self, sections=tuple(sections))

    def to_json(self) -> str:
        payload = {"schema": "track-design-v1", **{
            key: getattr(self, key) for key in (
                "maximum_spacing", "start_heading", "start_north", "start_east",
                "allow_curvature_jumps", "jump_ramp_length")},
            "sections": [{field_name: getattr(spec, field_name)
                          for field_name in SectionSpec.__dataclass_fields__} for spec in self.sections]}
        return json.dumps(payload, indent=2, sort_keys=True, allow_nan=False) + "\n"

    @classmethod
    def from_json(cls, text: str) -> "CourseDesign":
        try:
            payload: dict[str, Any] = json.loads(text)
        except json.JSONDecodeError as error:
            raise ValueError(f"not a track design file: {error}") from error
        if not isinstance(payload, dict) or payload.get("schema") != "track-design-v1":
            raise ValueError("not a track design file: the schema must be track-design-v1")
        names = SectionSpec.__dataclass_fields__
        sections = []
        for row in payload.get("sections", []):
            unknown = set(row) - set(names)
            if unknown:
                raise ValueError(f"unknown section field {sorted(unknown)}")
            sections.append(SectionSpec(**row))
        settings = {key: payload[key] for key in (
            "maximum_spacing", "start_heading", "start_north", "start_east",
            "allow_curvature_jumps", "jump_ramp_length") if key in payload}
        return cls(sections=tuple(sections), **settings)


def acceleration_design() -> CourseDesign:
    """The FSAE acceleration course, the same sections as ``fsae.acceleration_course``."""
    total = fsae.ACCELERATION_STAGING_OFFSET + fsae.ACCELERATION_LENGTH
    return CourseDesign(
        sections=(SectionSpec("straight", "acceleration course", length=total),),
        maximum_spacing=fsae.ACCELERATION_NODE_SPACING,
    )


def skidpad_design(transition_length: float = 0.0) -> CourseDesign:
    """The FSAE skidpad, the same sections as ``fsae.skidpad_course(transition_length)``."""
    if transition_length < 0.0 or not math.isfinite(transition_length):
        raise ValueError("the transition length must be zero or positive")
    radius = fsae.SKIDPAD_CIRCLE_RADIUS
    curvature = 1.0 / radius
    rows = [SectionSpec("straight", "entry", length=fsae.SKIDPAD_ENTRY_LENGTH)]
    rate = 2.0 * curvature / transition_length if transition_length > 0.0 else 0.0

    def link(start, end, name):
        return SectionSpec("clothoid", name, curvature=start, end_curvature=end, rate=rate)

    if transition_length > 0.0:
        rows.append(link(0.0, curvature, "entry transition"))
    rows += [SectionSpec("arc-angle", "right lap 1 (untimed)", radius=radius, angle_deg=360.0),
             SectionSpec("arc-angle", "right lap 2 (timed)", radius=radius, angle_deg=360.0)]
    if transition_length > 0.0:
        rows.append(link(curvature, -curvature, "right-to-left transition"))
    rows += [SectionSpec("arc-angle", "left lap 1 (untimed)", radius=radius, angle_deg=-360.0),
             SectionSpec("arc-angle", "left lap 2 (timed)", radius=radius, angle_deg=-360.0)]
```

```python
"""Write and check track files for the track GUI."""
from __future__ import annotations

import os
import re
import tempfile
from dataclasses import dataclass
from pathlib import Path

from simplified_vehicle_models.tracks.profile import load_track
from tools.gui_common.files import (check_name, generated_by, protected_directory_problem)
from tools.tracks.open_course import OpenCourse, write_course

MODEL_ID_PATTERN = re.compile(r"[A-Za-z0-9][A-Za-z0-9_.-]{0,79}")


class SaveRefused(Exception):
    """The save was refused by a safety rule. The message says which rule and what to do."""


@dataclass(frozen=True, slots=True)
class SavedTrack:
    xml: Path
    csv: Path
    length: float
    is_closed: bool
    node_count: int


def check_model_id(value: str) -> str:
    if not MODEL_ID_PATTERN.fullmatch(value or ""):
        raise ValueError("the model id must be 1 to 80 characters of letters, digits, '.', '_' or '-', "
                         "and must start with a letter or digit")
    return value


def check_title(value: str) -> str:
    if not value.strip() or len(value) > 120 or "\n" in value:
        raise ValueError("the title must be one line of 1 to 120 characters")
    return value


def _guard_targets(directory: Path, stem: str, *, allow_models: bool, overwrite: bool,
                   overwrite_generated: bool) -> None:
    problem = protected_directory_problem(directory, allow_models=allow_models)
    if problem:
        raise SaveRefused(problem)
    for suffix in (".xml", ".csv"):
        target = directory / f"{stem}{suffix}"
        if not target.exists():
            continue
        generator = generated_by(target) if suffix == ".xml" else None
        if generator and not overwrite_generated:
            raise SaveRefused(f"{target} is generated by {generator}. Change the file name, or confirm "
                              f"that you want to replace a generated file")
        if not overwrite:
            raise SaveRefused(f"{target} already exists. Change the file name, or confirm the overwrite")


def _install(temporary: Path, directory: Path, stem: str) -> tuple[Path, Path]:
    directory.mkdir(parents=True, exist_ok=True)
    csv_target, xml_target = directory / f"{stem}.csv", directory / f"{stem}.xml"
    # The CSV goes first: an XML that points at a missing CSV is the worse half-state.
    os.replace(temporary / f"{stem}.csv", csv_target)
    os.replace(temporary / f"{stem}.xml", xml_target)
    return xml_target, csv_target


def save_open_course(course: OpenCourse, directory: Path, stem: str, model_id: str, title: str,
                     comments: list[str] = (), *, allow_models: bool = False, overwrite: bool = False,
                     overwrite_generated: bool = False) -> SavedTrack:
    """Write an open course after every check, and read it back with ``load_track``.

    Nothing reaches ``directory`` unless the files load as a valid open track.
    """
    directory = Path(directory)
    check_name(stem, "file name")
    check_model_id(model_id)
    check_title(title)
    _guard_targets(directory, stem, allow_models=allow_models, overwrite=overwrite,
                   overwrite_generated=overwrite_generated)
    with tempfile.TemporaryDirectory() as folder:
        scratch = Path(folder)
        xml_path, _ = write_course(course, scratch, stem, model_id, title, list(comments))
        profile = load_track(xml_path)
        if profile.is_closed:
            raise ValueError("the written track loaded as a closed track")
        xml_target, csv_target = _install(scratch, directory, stem)
    return SavedTrack(xml_target, csv_target, float(profile.lap_length), False, int(profile.distance.size))


def describe_course(course: OpenCourse) -> dict[str, float]:
    """Return the numbers the status line shows."""
    import numpy as np

    curvature = np.asarray(course.curvature)
    peak = float(np.max(np.abs(curvature))) if curvature.size else 0.0
    return {
        "length_m": float(course.length),
        "nodes": int(len(course.distance)),
        "minimum_radius_m": (1.0 / peak) if peak > 1.0e-9 else float("inf"),
        "heading_change_deg": float(np.degrees(course.heading[-1] - course.heading[0])),
        "jumps": len(course.curvature_jumps),
    }
```

```python
"""Build a closed track from MAT telemetry, for the track GUI.

This needs SciPy, which is an optional dependency (``forward`` extra).
"""
from __future__ import annotations

import math
import tempfile
from dataclasses import dataclass
from pathlib import Path

from simplified_vehicle_models.tracks.profile import load_track
from tools.gui_common.files import check_name
from tools.track_gui.export import SavedTrack, SaveRefused, _guard_targets, _install, check_model_id, check_title


def scipy_available() -> bool:
    try:
        import scipy.io  # noqa: F401
    except ImportError:
        return False
    return True


@dataclass(frozen=True, slots=True)
class ClosedSettings:
    telemetry: Path
    start_time: float
    end_time: float
    spacing: float = 0.5
    smoothing: float = 2.0
    maximum_radius: float = 300.0

    def check(self) -> None:
        values = (self.start_time, self.end_time, self.spacing, self.smoothing, self.maximum_radius)
        if not all(math.isfinite(value) for value in values):
            raise ValueError("every number must be finite")
        if not self.start_time < self.end_time:
            raise ValueError("the lap start time must be before the end time")
        if self.spacing <= 0.0 or self.smoothing < 0.0 or self.maximum_radius <= 0.0:
            raise ValueError("spacing and maximum radius must be positive, and smoothing must not be negative")
        if not Path(self.telemetry).is_file():
            raise ValueError(f"no such telemetry file: {self.telemetry}")


def build_closed(settings: ClosedSettings) -> dict:
    """Return the geometry dict of ``build_closed_track.build_geometry``."""
    if not scipy_available():
        raise ValueError("SciPy is not installed; install it with: pip install -e .[forward]")
    from tools.tracks.build_closed_track import build_geometry

    settings.check()
    return build_geometry(Path(settings.telemetry).expanduser().resolve(), settings.start_time,
                          settings.end_time, settings.spacing, settings.smoothing)


def summarize(geometry: dict) -> dict[str, float]:
    """Return the report figures as numbers, for a table. ``build_closed_track.report`` prints them."""
    return {
        "length_m": float(geometry["length"]),
        "nodes": int(len(geometry["distance"])),
        "closure_gap_m": float(geometry["closure_gap"]),
        # One full turn either way is correct: counter-clockwise gives -2*pi, clockwise +2*pi.
        "winding_error_rad": abs(abs(float(geometry["winding"])) - 2.0 * math.pi),
        "winding_rad": float(geometry["winding"]),
        "minimum_radius_m": float(geometry["minimum_radius"]),
        "minimum_self_distance_m": float(geometry["minimum_self_distance"]),
        "peak_smoothing_move_m": float(geometry["peak_smoothing_correction"]),
    }


def save_closed(geometry: dict, settings: ClosedSettings, directory: Path, stem: str, model_id: str,
                title: str, *, allow_models: bool = False, overwrite: bool = False,
                overwrite_generated: bool = False) -> SavedTrack:
    """Write a closed track and read it back with ``load_track`` before it reaches ``directory``."""
    from tools.tracks.build_closed_track import write_csv, write_xml

    directory = Path(directory)
    check_name(stem, "file name")
    check_model_id(model_id)
    check_title(title)
    _guard_targets(directory, stem, allow_models=allow_models, overwrite=overwrite,
                   overwrite_generated=overwrite_generated)
    telemetry = Path(settings.telemetry).expanduser().resolve()
    with tempfile.TemporaryDirectory() as folder:
        scratch = Path(folder)
        write_csv(scratch / f"{stem}.csv", geometry)
        write_xml(scratch / f"{stem}.xml", f"{stem}.csv", geometry, telemetry,
                  settings.maximum_radius, settings.spacing, settings.smoothing,
                  model_id=model_id, title=title)
        profile = load_track(scratch / f"{stem}.xml")
        if not profile.is_closed:
            raise ValueError("the written track loaded as an open track")
        xml_target, csv_target = _install(scratch, directory, stem)
    return SavedTrack(xml_target, csv_target, float(profile.lap_length), True, int(profile.distance.size))
```

```python
from tools.track_gui.design import KINDS, SectionSpec

COLUMNS = [("kind", "Type"), ("name", "Name"), ("length", "Length (m)"), ("radius", "Radius (m)"),
           ("angle_deg", "Angle (deg)"), ("curvature", "Curvature (1/m)"),
           ("end_curvature", "End curvature (1/m)"), ("rate", "Rate (1/m²)")]

#: Which numeric columns each kind reads. The other cells are shown greyed and ignored.
USED = {"straight": {"length"}, "arc": {"length", "curvature"}, "arc-angle": {"radius", "angle_deg"},
        "clothoid": {"curvature", "end_curvature", "rate"}}


class SectionTableModel(QAbstractTableModel):
    changed = pyqtSignal()

    def __init__(self, sections=(), parent=None) -> None:
        super().__init__(parent)
        self._rows: list[SectionSpec] = list(sections)

    def sections(self) -> tuple[SectionSpec, ...]:
        return tuple(self._rows)

    def set_sections(self, sections) -> None:
        self.beginResetModel()
        self._rows = list(sections)
        self.endResetModel()
        self.changed.emit()

    def rowCount(self, parent=QModelIndex()) -> int:
        return 0 if parent.isValid() else len(self._rows)

    def columnCount(self, parent=QModelIndex()) -> int:
        return 0 if parent.isValid() else len(COLUMNS)

    def headerData(self, section, orientation, role=Qt.ItemDataRole.DisplayRole):
        if role == Qt.ItemDataRole.DisplayRole:
            return COLUMNS[section][1] if orientation == Qt.Orientation.Horizontal else str(section + 1)
        return None

    def flags(self, index):
        flags = Qt.ItemFlag.ItemIsSelectable | Qt.ItemFlag.ItemIsEnabled
        key = COLUMNS[index.column()][0]
        row = self._rows[index.row()]
        if key in ("kind", "name") or key in USED[row.kind]:
            flags |= Qt.ItemFlag.ItemIsEditable
        return flags

    def data(self, index, role=Qt.ItemDataRole.DisplayRole):
        key = COLUMNS[index.column()][0]
        row = self._rows[index.row()]
        value = getattr(row, key)
        if role in (Qt.ItemDataRole.DisplayRole, Qt.ItemDataRole.EditRole):
            return value if isinstance(value, str) else f"{value:.10g}"
        if role == Qt.ItemDataRole.ForegroundRole and key not in ("kind", "name") and key not in USED[row.kind]:
            from PyQt6.QtGui import QColor
            return QColor(170, 170, 170)
        return None

    def setData(self, index, value, role=Qt.ItemDataRole.EditRole) -> bool:
        if role != Qt.ItemDataRole.EditRole:
            return False
        key = COLUMNS[index.column()][0]
        row = self._rows[index.row()]
        try:
            if key == "kind":
                if str(value) not in KINDS:
                    return False
                new = replace(row, kind=str(value))
            elif key == "name":
                new = replace(row, name=str(value))
            else:
                number = float(value)
                new = replace(row, **{key: number})
        except ValueError:
            return False
        self._rows[index.row()] = new
        self.dataChanged.emit(self.index(index.row(), 0), self.index(index.row(), len(COLUMNS) - 1))
        self.changed.emit()
        return True

    def add(self, kind: str = "straight", after: int | None = None) -> int:
        position = len(self._rows) if after is None else after + 1
        self.beginInsertRows(QModelIndex(), position, position)
        self._rows.insert(position, SectionSpec(kind=kind))
        self.endInsertRows()
        self.changed.emit()
        return position

    def remove(self, row: int) -> None:
        if 0 <= row < len(self._rows):
            self.beginRemoveRows(QModelIndex(), row, row)
            del self._rows[row]
            self.endRemoveRows()
            self.changed.emit()

    def move(self, row: int, offset: int) -> int:
        target = row + offset
        if not (0 <= row < len(self._rows) and 0 <= target < len(self._rows)):
            return row
        rows = list(self._rows)
        rows[row], rows[target] = rows[target], rows[row]
        self.set_sections(rows)
        return target
```

```python
"""Two plain QPainter plots: the course in the XY plane and curvature against distance."""
from __future__ import annotations

import math

import numpy as np
from PyQt6.QtCore import QPointF, QRectF, Qt
from PyQt6.QtGui import QColor, QPainter, QPainterPath, QPen
from PyQt6.QtWidgets import QWidget

MARGIN = 36
GRID = QColor(210, 210, 210)
LINE = QColor(20, 90, 170)
MARK = QColor(200, 60, 30)


def nice_step(span: float, target: int = 5) -> float:
    """Return a 1, 2 or 5 times a power of ten that gives about ``target`` steps over ``span``."""
    if not math.isfinite(span) or span <= 0.0:
        return 1.0
    raw = span / target
    power = 10.0 ** math.floor(math.log10(raw))
    for factor in (1.0, 2.0, 5.0, 10.0):
        if raw <= factor * power:
            return factor * power
    return 10.0 * power


class _Plot(QWidget):
    def __init__(self, parent=None) -> None:
        super().__init__(parent)
        self.setMinimumSize(240, 200)
        self.message = "no course"

    def set_message(self, text: str) -> None:
        self.message = text
        self.update()

    def _frame(self, painter: QPainter) -> QRectF:
        painter.fillRect(self.rect(), Qt.GlobalColor.white)
        return QRectF(MARGIN, 8, max(self.width() - MARGIN - 8, 10), max(self.height() - MARGIN - 8, 10))

    def _empty(self, painter: QPainter) -> None:
        painter.setPen(QColor(120, 120, 120))
        painter.drawText(self.rect(), Qt.AlignmentFlag.AlignCenter, self.message)


class CoursePlot(_Plot):
    """The course in map form. North is up and east is right, with equal scale on both axes."""

    def __init__(self, parent=None) -> None:
        super().__init__(parent)
        self.north = np.zeros(0)
        self.east = np.zeros(0)
        self.boundary_points: list[tuple[float, float]] = []

    def set_course(self, north, east, boundary_points=()) -> None:
        self.north, self.east = np.asarray(north, float), np.asarray(east, float)
        self.boundary_points = list(boundary_points)
        self.message = "no course" if self.north.size == 0 else ""
        self.update()

    def transform(self, rect: QRectF):
        """Return a function from (north, east) to a widget point, with equal scale."""
        e0, e1 = float(self.east.min()), float(self.east.max())
        n0, n1 = float(self.north.min()), float(self.north.max())
        span_e, span_n = max(e1 - e0, 1e-6), max(n1 - n0, 1e-6)
        scale = min(rect.width() / span_e, rect.height() / span_n)
        left = rect.left() + (rect.width() - span_e * scale) / 2.0
        bottom = rect.bottom() - (rect.height() - span_n * scale) / 2.0
        return lambda n, e: QPointF(left + (e - e0) * scale, bottom - (n - n0) * scale), scale

    def paintEvent(self, _event) -> None:
        painter = QPainter(self)
        painter.setRenderHint(QPainter.RenderHint.Antialiasing)
        rect = self._frame(painter)
        if self.north.size < 2:
            self._empty(painter)
            return
        to_point, scale = self.transform(rect)
        painter.setPen(QPen(GRID, 1))
        step = nice_step(min(rect.width(), rect.height()) / scale)
        n_min, e_min = float(self.north.min()), float(self.east.min())
        n = math.floor(n_min / step) * step
        while to_point(n, e_min).y() > rect.top() - 1:
            y = to_point(n, e_min).y()
            if rect.top() <= y <= rect.bottom():
                painter.drawLine(QPointF(rect.left(), y), QPointF(rect.right(), y))
                painter.drawText(QPointF(2, y + 4), f"{n:g}")
            n += step
        e = math.floor(e_min / step) * step
        while to_point(n_min, e).x() < rect.right() + 1:
            x = to_point(n_min, e).x()
            if rect.left() <= x <= rect.right():
                painter.drawLine(QPointF(x, rect.top()), QPointF(x, rect.bottom()))
                painter.drawText(QPointF(x - 8, rect.bottom() + 14), f"{e:g}")
            e += step
        path = QPainterPath(to_point(self.north[0], self.east[0]))
        for n_value, e_value in zip(self.north[1:], self.east[1:]):
            path.lineTo(to_point(n_value, e_value))
        painter.setPen(QPen(LINE, 2))
        painter.drawPath(path)
        painter.setPen(QPen(MARK, 1))
        painter.setBrush(MARK)
        for n_value, e_value in self.boundary_points:
            painter.drawEllipse(to_point(n_value, e_value), 3, 3)
        painter.setBrush(Qt.GlobalColor.darkGreen)
        painter.drawEllipse(to_point(self.north[0], self.east[0]), 5, 5)
        painter.setPen(QColor(90, 90, 90))
        painter.drawText(QPointF(rect.left() + 4, rect.top() + 12), "east →, north ↑ (m)")


class CurvaturePlot(_Plot):
    """Curvature (1/m, right turn positive) against distance, with the section boundaries."""

    def __init__(self, parent=None) -> None:
        super().__init__(parent)
        self.distance = np.zeros(0)
        self.curvature = np.zeros(0)
        self.boundaries: list[float] = []

    def set_course(self, distance, curvature, boundaries=()) -> None:
        self.distance, self.curvature = np.asarray(distance, float), np.asarray(curvature, float)
        self.boundaries = [float(b) for b in boundaries]
        self.message = "no course" if self.distance.size == 0 else ""
        self.update()

    def limits(self) -> tuple[float, float, float, float]:
        peak = max(float(np.max(np.abs(self.curvature))), 1e-3)
        return float(self.distance[0]), float(self.distance[-1]), -1.1 * peak, 1.1 * peak

    def paintEvent(self, _event) -> None:
        painter = QPainter(self)
        painter.setRenderHint(QPainter.RenderHint.Antialiasing)
        rect = self._frame(painter)
        if self.distance.size < 2:
            self._empty(painter)
            return
        x0, x1, y0, y1 = self.limits()

        def to_point(x, y):
            return QPointF(rect.left() + (x - x0) / max(x1 - x0, 1e-9) * rect.width(),
                           rect.bottom() - (y - y0) / (y1 - y0) * rect.height())

        painter.setPen(QPen(GRID, 1))
        zero = to_point(x0, 0.0).y()
        painter.drawLine(QPointF(rect.left(), zero), QPointF(rect.right(), zero))
        for boundary in self.boundaries:
            x = to_point(boundary, 0.0).x()
            painter.drawLine(QPointF(x, rect.top()), QPointF(x, rect.bottom()))
        step = nice_step(x1 - x0)
        x = math.ceil(x0 / step) * step
        while x <= x1:
            painter.drawText(QPointF(to_point(x, 0.0).x() - 8, rect.bottom() + 14), f"{x:g}")
            x += step
        painter.drawText(QPointF(2, rect.top() + 10), f"{y1:.3g}")
        painter.drawText(QPointF(2, rect.bottom()), f"{y0:.3g}")
        path = QPainterPath(to_point(self.distance[0], self.curvature[0]))
        for d, c in zip(self.distance[1:], self.curvature[1:]):
            path.lineTo(to_point(d, c))
        painter.setPen(QPen(LINE, 2))
        painter.drawPath(path)
        painter.setPen(QColor(90, 90, 90))
        painter.drawText(QPointF(rect.left() + 4, rect.top() + 12), "curvature (1/m) against distance (m)")
```

```python
class _BuildWorker(QObject):
    done = pyqtSignal(object)
    failed = pyqtSignal(str)

    def __init__(self, settings) -> None:
        super().__init__()
        self.settings = settings

    def run(self) -> None:
        try:
            self.done.emit(closed.build_closed(self.settings))
        except Exception as error:  # the worker must never let an exception end the thread silently
            self.failed.emit(str(error))
```

````markdown
# Track GUI

The track GUI makes track models for the simulators. It has two modes. In the first mode you design an open course from sections. In the second mode you build a closed track from MAT telemetry. The GUI writes new files. It does not change a committed track.

## Install

## Design an open course

Use the tab **Design an open course**. The section table has one row for each section. The types are `straight`, `arc`, `arc-angle` and `clothoid`. A right turn has a positive curvature. Each type reads only some columns. The GUI greys the cells that it ignores.

| Type | Columns it reads |
|---|---|
| `straight` | Length |
| `arc` | Length, Curvature |
| `arc-angle` | Radius, Angle |
| `clothoid` | Curvature, End curvature, Rate |

Select a preset and **Load preset** to start from the committed acceleration or skidpad course. The presets build the same course as `tools/tracks/build_fsae_dynamic_tracks.py`. The build settings are the node spacing, the start heading, the start position, the curvature-jump switch and the jump ramp length.

The two plots update after each edit. The first plot shows the centerline. The second plot shows the curvature against the distance. Both mark the section boundaries. The line under the table shows the length, the node count, the minimum radius, the heading change and the number of curvature jumps. When the design is not valid, the line shows the reason and **Save track** is off.

**Save design…** writes the sections and settings to a JSON file. **Open design…** reads it again. Saving inside `models/` needs **Allow writing inside models/**. If the target exists, the GUI asks before it replaces the file, even when **Overwrite existing files** is checked.

## Build a closed track from telemetry

Use the tab **Closed track from telemetry**. Select the MAT file, the lap start and end times, the node spacing, the smoothing length and the maximum radius. Select **Build**. The build runs in a background thread, so the window stays usable. The result box lists the length, the node count, the closure gap, the winding error, the minimum radius, the minimum self-distance and the largest smoothing move. Check these figures before you save.

## Save a track

The save bar has a folder, a file name, a model id and a title. The GUI writes `<file name>.xml` and `<file name>.csv`. It writes them in a temporary folder first, reads them back with `load_track`, and only then moves them to the folder. If the read-back fails, nothing reaches the folder.

The GUI applies these rules:

- The default folder is `tracks_out/` in the repository root. Git ignores it.
- A folder inside `models/` is refused unless you tick **Allow writing inside models/**.
- An existing file is refused unless you tick **Overwrite existing files**.
- A file that carries a `Generated by tools/...` comment needs a second confirmation. The message names the tool that normally writes it.
- The file name has 1 to 40 letters, numbers, `_` or `-`. The model id has 1 to 80 letters, digits, `.`, `_` or `-`, and starts with a letter or a digit. The title is one line of 1 to 120 characters.

The simulation GUI lists only `closed-xy-profile` tracks. An open course does not appear in its track list. This is intended. To use a closed track there, save it inside `models/`.
````
