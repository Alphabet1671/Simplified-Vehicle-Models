# Vehicle GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A PyQt6 program, `tools/vehicle_gui/`, that opens a vehicle model, edits component parameters, swaps components, checks the result with the real compiler, and saves it as new model files.

**Architecture:**
- A Qt-free core (`xmltext.py`, `model.py`, `save.py`) and a thin `qt/` layer, as in `tools/sim_gui/`.
- The slot tree, the candidates and the swap rule come from `tools/sim_gui/catalogue.py` and `tools/sim_gui/vehicle.py` (read-only imports).
- Edits are made on the text of the XML files, so comments and layout stay. A save never writes an original file.
- The compiler (`compile_formulation`) is the only judge of a vehicle. The GUI shows its answer.

**Tech Stack:** Python 3.12+, PyQt6 ≥ 6.5 (6.11.0 is installed), numpy, `unittest`, `xml.etree.ElementTree`.

**Spec:** `docs/superpowers/specs/2026-10-19-gui-wrappers-investigation.md`, sections 1, 5, 7 and 8.

## Global Constraints

- Change nothing in `src/`. Do not edit the files of the simulation GUI (`tools/sim_gui/`). Read-only imports from it are listed under Fixed Decisions.
- Only `qt/` modules, `app.py` and the Qt tests import PyQt6. Every other new module imports only the standard library, numpy and the repository.
- PyQt6 stays an optional extra: `gui = ["PyQt6>=6.5"]` is already in `pyproject.toml`. Do not change `pyproject.toml`.
- Make it cross-platform. Use `pathlib`, `sys.executable`, and `QProcess` or `subprocess` with argument lists. Never use a shell. Do not use POSIX-only calls such as signals, `fork` or `timeout`.
- Write files atomically: write `<name>.tmp`, then `os.replace`. Write JSON with `indent=2, sort_keys=True, allow_nan=False`.
- A GUI never writes into `models/` unless the user ticks a confirmation. It never overwrites a file unless the user ticks a second confirmation.
- Write the docs in ASD-STE100 style: short sentences, one idea in each sentence.
- Run tests as `MPLCONFIGDIR=/tmp/mplcfg PYTHONPATH=src:. QT_QPA_PLATFORM=offscreen python3 -m unittest tests.<module> -v`. Qt tests skip when PyQt6 is not installed.
- Every Qt test that creates a window stubs `QMessageBox.question`, `warning` and `information` in `setUp` and restores them with `addCleanup`. An unstubbed modal dialog hangs the test run.
- Name each new tool file so that no other `tools/*/` folder holds a file of the same name. `tests/test_default_track.py` globs `tools/*/<name>` and expects one match.
- Run a time-limited command with a Python `subprocess.run(..., timeout=N)` wrapper. macOS has no `timeout` command.
- The default output folder is `vehicles_out/` in the repository root. Add `/vehicles_out/` to `.gitignore`.
- Many tests pin the sha256 of files under `models/`. The GUI and its tests never write inside `models/`. `models/sweeps/` is git-ignored and exempt.
- A save writes nothing if the compiler rejects the vehicle.
- Files that carry a `Generated by tools/...` comment are read-only in the GUI. A swap of such a slot is allowed.

## Output Layout

A save stages every output in a temporary sibling directory using `atomic_write_text`. After the complete set passes compilation, it commits the set as one transaction. A normal in-process replacement failure restores existing bytes and removes newly moved files. If a restore action fails, cleanup continues for every item, the original error remains raised, and the staging/backup directory is retained with a recovery path note; the affected target may be missing until recovery. Abrupt process termination or power loss during commit is outside the guarantee. Same-stem outputs from an earlier save are included in the transaction: stale files matching `<stem>__*.xml` are backed up and removed, then restored on failure, so a successful save cannot leave orphaned old variants. Files that did not change stay where they are and are referenced. `save_component` stages and validates its one output before an atomic replacement.

```text
vehicles_out/
├── <name>__formulation.xml     # open this in the simulation GUI
├── <name>__vehicle.xml         # the assembly, with the changed refs
└── <name>__<slot>.xml          # each edited slot and each parent of an edited or swapped slot
```

A slot path uses `__` for `/`. The slot `powertrain/power-plant` gives `<name>__powertrain__power-plant.xml`. Each copy has the line `<!-- Saved by tools/vehicle_gui from <original path>. -->` after the XML declaration.

**`tools/vehicle_gui/xmltext.py`**

```python
"""Edit model XML as text, so comments, spacing and line order stay as they are.

``ElementTree`` cannot do this: it drops comments and rewrites ``<x />`` spacing, which
changes the bytes of 35 of the 62 files in ``models/``. Every function here changes only the
attribute it names, and never looks inside a comment.
"""
from __future__ import annotations

import math
import os
import re
from pathlib import Path

_COMMENT = re.compile(r"(<!--.*?-->)", re.S)
_PARAMETER = re.compile(r'(<parameter\b[^<>]*?\bname="(?P<name>[^"]+)"[^<>]*?\bvalue=")(?P<value>[^"]*)(")')
_UNIT = re.compile(r'<parameter\b[^<>]*?\bname="(?P<name>[^"]+)"[^<>]*?\bunit="(?P<unit>[^"]*)"')
_ROOT_ID = re.compile(r'(<model\b[^<>]*?\bid=")([^"]*)(")')
_REFERENCE_TAG = re.compile(r"<(?:component|source|data)\b[^<>]*>")
_ATTRIBUTE = re.compile(r'\b(ref|path)="([^"]*)"')
_COMPONENT = re.compile(r'<component\b[^<>]*\brole="(?P<role>[^"]+)"[^<>]*>')
_SOURCE = re.compile(r"<source\b[^<>]*>")


def _map_code(text: str, function) -> str:
    """Apply ``function`` to every stretch of text outside ``<!-- ... -->``."""
    return "".join(part if part.startswith("<!--") else function(part) for part in _COMMENT.split(text))


def parameter_values(text: str) -> dict[str, str]:
    """Return ``{name: value text}`` for every ``<parameter>`` outside comments."""
    found: dict[str, str] = {}

    def scan(code: str) -> str:
        for match in _PARAMETER.finditer(code):
            found[match.group("name")] = match.group("value")
        return code

    _map_code(text, scan)
    return found


def parameter_units(text: str) -> dict[str, str]:
    units: dict[str, str] = {}

    def scan(code: str) -> str:
        for match in _UNIT.finditer(code):
            units[match.group("name")] = match.group("unit")
        return code

    _map_code(text, scan)
    return units


def format_number(value: float) -> str:
    """Return the shortest text that reads back as exactly ``value``."""
    value = float(value)
    if not math.isfinite(value):
        raise ValueError(f"a parameter value must be finite: {value}")
    return repr(value)


def set_parameters(text: str, values: dict[str, float]) -> str:
    """Set ``value=`` of the named parameters. Unknown names raise ``ValueError``."""
    pending = {name: format_number(value) for name, value in values.items()}

    def edit(code: str) -> str:
        def one(match):
            name = match.group("name")
            if name in pending:
                return match.group(1) + pending.pop(name) + match.group(4)
            return match.group(0)

        return _PARAMETER.sub(one, code)

    result = _map_code(text, edit)
    if pending:
        raise ValueError(f"no such parameter: {', '.join(sorted(pending))}")
    return result


def model_id(text: str) -> str:
    match = _ROOT_ID.search(_COMMENT.sub("", text))
    if match is None:
        raise ValueError("the file has no model id")
    return match.group(2)


def set_model_id(text: str, new_id: str) -> str:
    """Set the root ``id``. The new id must not contain a quote or an angle bracket."""
    if not new_id or any(character in new_id for character in '"<>&\n'):
        raise ValueError(f"not a usable model id: {new_id!r}")
    done: list[int] = []

    def edit(code: str) -> str:
        if done:
            return code

        def one(match):
            done.append(1)
            return match.group(1) + new_id + match.group(3)

        return _ROOT_ID.sub(one, code, count=1)

    result = _map_code(text, edit)
    if not done:
        raise ValueError("the file has no model id")
    return result


def _set_ref(tag: str, ref: str) -> str:
    return _ATTRIBUTE.sub(lambda a: f'ref="{ref}"' if a.group(1) == "ref" else a.group(0), tag, count=0)


def _check_ref(ref: str) -> str:
    if not ref or any(character in ref for character in '"<>&\n'):
        raise ValueError(f"not a usable reference: {ref!r}")
    return ref


def set_component_ref(text: str, role: str, ref: str) -> str:
    """Point the ``<component role=...>`` at ``ref``."""
    _check_ref(ref)
    done: list[int] = []

    def edit(code: str) -> str:
        def one(match):
            if match.group("role") != role:
                return match.group(0)
            done.append(1)
            return _set_ref(match.group(0), ref)

        return _COMPONENT.sub(one, code)

    result = _map_code(text, edit)
    if not done:
        raise ValueError(f"no component with role {role!r}")
    return result


def set_source_ref(text: str, ref: str) -> str:
    """Point the first ``<source>`` of a formulation at ``ref``."""
    _check_ref(ref)
    done: list[int] = []

    def edit(code: str) -> str:
        def one(match):
            if done:
                return match.group(0)
            done.append(1)
            return _set_ref(match.group(0), ref)

        return _SOURCE.sub(one, code)

    result = _map_code(text, edit)
    if not done:
        raise ValueError("the file has no source element")
    return result


def reanchor(text: str, source_directory: Path, target_directory: Path) -> str:
    """Rewrite relative ``ref`` and ``path`` attributes so they still work from ``target_directory``."""
    source_directory, target_directory = Path(source_directory).resolve(), Path(target_directory).resolve()
    if source_directory == target_directory:
        return text

    def fix(match):
        value = match.group(2)
        if Path(value).is_absolute():
            return match.group(0)
        target = (source_directory / value).resolve()
        return f'{match.group(1)}="{Path(os.path.relpath(target, target_directory)).as_posix()}"'

    return _map_code(text, lambda code: _REFERENCE_TAG.sub(lambda tag: _ATTRIBUTE.sub(fix, tag.group(0)), code))
```

```python
"""An editable vehicle: parameter edits and component swaps on top of a configuration.

Nothing here writes a file. ``tools.vehicle_gui.save`` turns a ``VehicleEdit`` into files.
"""
from __future__ import annotations

import math
from dataclasses import dataclass, field, replace
from pathlib import Path

from tools.gui_common.files import generated_by
from tools.sim_gui.vehicle import VehicleConfiguration
from tools.vehicle_gui import xmltext

ASSEMBLY = ""  # the slot key of the vehicle assembly file itself


@dataclass(frozen=True, slots=True)
class ParameterRow:
    name: str
    original: str       # the value text in the file
    unit: str
    edited: float | None

    @property
    def value_text(self) -> str:
        return self.original if self.edited is None else xmltext.format_number(self.edited)

    @property
    def numeric(self) -> bool:
        try:
            float(self.original)
        except ValueError:
            return False
        return True


@dataclass(frozen=True, slots=True)
class VehicleEdit:
    configuration: VehicleConfiguration
    baseline: VehicleConfiguration
    parameters: dict[str, dict[str, float]] = field(default_factory=dict)

    @classmethod
    def open(cls, path: Path) -> "VehicleEdit":
        configuration = VehicleConfiguration.open(Path(path))
        if configuration.formulation is None:
            raise ValueError("vehicle GUI requires a vehicle-formulation; a bare vehicle-assembly has no subtype")
        if configuration.model not in {"planar-7dof", "14dof-simple"}:
            raise ValueError(f"unsupported vehicle formulation subtype: {configuration.model}")
        return cls(configuration, configuration, {})

    # -- reading ----------------------------------------------------------------------------
    def keys(self) -> tuple[str, ...]:
        """The slot keys, with the assembly first."""
        return (ASSEMBLY, *(slot.key for slot in self.configuration.slots()))

    def file(self, key: str) -> Path:
        if key == ASSEMBLY:
            return self.configuration.assembly
        try:
            return self.configuration.choices[key]
        except KeyError:
            raise ValueError(f"unknown slot {key!r}") from None

    def generator(self, key: str) -> str | None:
        """The tool that generated this slot's file, or None when it is hand-written."""
        return generated_by(self.file(key))

    def rows(self, key: str) -> list[ParameterRow]:
        text = self.file(key).read_text(encoding="utf-8")
        units = xmltext.parameter_units(text)
        edits = self.parameters.get(key, {})
        return [ParameterRow(name, value, units.get(name, ""), edits.get(name))
                for name, value in xmltext.parameter_values(text).items()]

    def swapped(self) -> tuple[str, ...]:
        return tuple(key for key in self.configuration.changed_from(self.baseline) if key != "model")

    def edited_keys(self) -> tuple[str, ...]:
        return tuple(key for key, values in self.parameters.items() if values)

    @property
    def changed(self) -> bool:
        return bool(self.swapped() or self.edited_keys())

    # -- changing (each returns a new VehicleEdit) --------------------------------------------
    def with_parameter(self, key: str, name: str, value: float) -> "VehicleEdit":
        if not math.isfinite(value):
            raise ValueError(f"{name}: the value must be finite")
        row = next((row for row in self.rows(key) if row.name == name), None)
        if row is None:
            raise ValueError(f"{key or 'assembly'} has no parameter {name!r}")
        if not row.numeric:
            raise ValueError(f"{name} is not a number and cannot be edited here")
        if self.generator(key):
            raise ValueError(f"{self.file(key).name} is generated by {self.generator(key)}. "
                             f"Change the inputs of that tool instead of the file")
        parameters = {k: dict(v) for k, v in self.parameters.items()}
        if value == float(row.original):
            parameters.get(key, {}).pop(name, None)
        else:
            parameters.setdefault(key, {})[name] = float(value)
        parameters = {k: v for k, v in parameters.items() if v}
        return replace(self, parameters=parameters)

    def without_parameter(self, key: str, name: str) -> "VehicleEdit":
        parameters = {k: dict(v) for k, v in self.parameters.items()}
        parameters.get(key, {}).pop(name, None)
        return replace(self, parameters={k: v for k, v in parameters.items() if v})

    def with_choice(self, key: str, path: Path) -> "VehicleEdit":
        configuration = self.configuration.with_choice(key, path)
        prefix = key + "/"
        parameters = {k: v for k, v in self.parameters.items() if k != key and not k.startswith(prefix)}
        return replace(self, configuration=configuration, parameters=parameters)

    def reset(self) -> "VehicleEdit":
        return replace(self, configuration=self.baseline, parameters={})
```

### Task 4: Add the compile check and the safe save

`render_files` makes the text of every file of a save. `check_files` writes them in a scratch folder and runs `compile_formulation` on them. `save_vehicle` and `save_component` write to the target folder only after the check passes. The originals are never written. A vehicle save is a directory transaction: render and validate in a temporary sibling directory, then move the complete validated set into the target. A normal in-process move failure rolls back all moved files and restores all backups. If any rollback action fails, cleanup continues, the original error remains raised, and the staging/backup directory is retained with a recovery-path note; the affected target may be missing until recovery. The implementation does not promise recovery after abrupt process termination or power loss during the multi-file commit. A bare-assembly formulation fallback is forbidden because bare assemblies are rejected at open time.

```python
"""Turn a ``VehicleEdit`` into files, and check them with the real compiler.

The rules, all enforced here and tested:
- The originals are never written. A save always makes copies named ``<stem>__<slot>.xml``.
- Only the changed files, and the files above them, are copied. Everything else is referenced.
- Comments, spacing and line order of the copies are the originals' (see ``xmltext``).
- The copies are compiled in a scratch folder first. Nothing reaches the target if that fails.
- A target inside ``models/`` needs ``allow_models``. An existing file needs ``overwrite``.
"""
from __future__ import annotations

import os
import re
import shutil
import tempfile
from dataclasses import dataclass
from pathlib import Path

from simplified_vehicle_models.compiler.compile import compile_formulation
from tools.gui_common import REPOSITORY_ROOT
from tools.gui_common.files import atomic_write_text, check_name, protected_directory_problem
from tools.vehicle_gui import xmltext
from tools.vehicle_gui.model import ASSEMBLY, VehicleEdit

_DECLARATION = re.compile(r"\A(<\?xml[^>]*\?>[ \t]*\r?\n)")
_GENERATED = re.compile(r"Generated by (tools/[\w./-]+)")


class SaveRefused(Exception):
    """A safety rule stopped the save. The message names the rule."""


@dataclass(frozen=True, slots=True)
class Validation:
    error: str | None
    unconsumed: tuple[str, ...] = ()
    unused_roles: tuple[str, ...] = ()

    @property
    def ok(self) -> bool:
        return self.error is None


@dataclass(frozen=True, slots=True)
class SavedVehicle:
    entry: Path                 # the saved vehicle-formulation entry
    files: tuple[Path, ...]
    validation: Validation


def _relative(target: Path, directory: Path) -> str:
    return Path(os.path.relpath(Path(target).resolve(), Path(directory).resolve())).as_posix()


def _declared_child(parent_file: Path, role: str) -> Path | None:
    """The file a parent's own ``<component role=...>`` points at."""
    from xml.etree import ElementTree

    for component in ElementTree.parse(parent_file).getroot().findall("./components/component"):
        if component.get("role") == role and component.get("ref"):
            return (Path(parent_file).parent / component.get("ref")).resolve()
    return None


def diverging_keys(edit: VehicleEdit) -> set[str]:
    """Slots whose file differs from what the parent file declares: the real swaps.

    ``VehicleConfiguration.changed_from`` also lists the children of a swapped component,
    because their paths differ. Those children are not swaps: the new parent brought them.
    """
    configuration = edit.configuration
    result = set()
    for key, path in configuration.choices.items():
        parent, _, role = key.rpartition("/")
        declared = _declared_child(edit.file(parent), role)
        if declared is None or declared != Path(path).resolve():
            result.add(key)
    return result


def _copied_keys(edit: VehicleEdit) -> set[str]:
    """The slots whose files are copied: edited slots, and every ancestor of an edited or swapped slot."""
    changed = set(edit.edited_keys()) | diverging_keys(edit)
    copied = {ASSEMBLY} | set(edit.edited_keys())
    for key in changed:
        parts = key.split("/")
        copied.update("/".join(parts[:count]) for count in range(1, len(parts)))
    return copied


def _mark_copy(text: str, source: Path) -> str:
    """Add a provenance comment, and stop a copy of a generated file claiming to be generated."""
    def neutral(match):
        return "<!--" + _GENERATED.sub(r"Derived from output of \1", match.group(0)[4:-3]).replace(
            "Do not edit.", "This copy was saved by tools/vehicle_gui.") + "-->"

    text = re.sub(r"<!--.*?-->", neutral, text, flags=re.S)
    try:
        origin = Path(source).resolve().relative_to(REPOSITORY_ROOT).as_posix()
    except ValueError:
        origin = Path(source).name
    note = f"<!-- Saved by tools/vehicle_gui from {origin}. -->\n"
    match = _DECLARATION.match(text)
    return text[:match.end()] + note + text[match.end():] if match else note + text


def _name(stem: str, key: str) -> str:
    if key == ASSEMBLY:
        return f"{stem}__vehicle.xml"
    return f"{stem}__{key.replace('/', '__')}.xml"


def render_files(edit: VehicleEdit, directory: Path, stem: str) -> list[tuple[Path, str]]:
    """Return ``(path, text)`` for every file of the save, children first, formulation last."""
    directory = Path(directory).resolve()
    check_name(stem, "file name")
    for key in edit.edited_keys():
        if edit.generator(key):
            raise ValueError(f"{edit.file(key).name} is generated by {edit.generator(key)} and cannot be edited")
    copied = _copied_keys(edit)
    swapped = diverging_keys(edit)
    paths = {key: directory / _name(stem, key) for key in copied}
    configuration = edit.configuration
    # VehicleEdit.open enforces formulation-only input.
    assert configuration.formulation is not None
    output: list[tuple[Path, str]] = []
    for key in sorted(copied, key=lambda k: (-(k.count("/") + (k != ASSEMBLY)), k)):
        source = edit.file(key)
        text = source.read_text(encoding="utf-8")
        text = xmltext.reanchor(text, source.parent, directory)
        text = xmltext.set_model_id(text, f"{xmltext.model_id(text)}.{stem}")
        if edit.parameters.get(key):
            text = xmltext.set_parameters(text, edit.parameters[key])
        prefix = f"{key}/" if key else ""
        for child in configuration.choices:
            if not child.startswith(prefix) or "/" in child[len(prefix):] or child == key:
                continue
            if child in copied or child in swapped:
                target = paths.get(child, configuration.choices[child])
                text = xmltext.set_component_ref(text, child[len(prefix):], _relative(target, directory))
        output.append((paths[key], _mark_copy(text, source)))
    source = configuration.formulation
    text = xmltext.reanchor(source.read_text(encoding="utf-8"), source.parent, directory)
    text = xmltext.set_model_id(text, f"{xmltext.model_id(text)}.{stem}")
    text = xmltext.set_source_ref(text, _relative(paths[ASSEMBLY], directory))
    output.append((directory / f"{stem}__formulation.xml", _mark_copy(text, source)))
    return output


def _compile(entry: Path):
    return compile_formulation(entry)


def check_files(edit: VehicleEdit, stem: str = "check") -> Validation:
    """Render the copies in a scratch folder and compile them. Takes about 0.05 s."""
    try:
        with tempfile.TemporaryDirectory() as folder:
            scratch = Path(folder)
            files = render_files(edit, scratch, stem)
            for path, text in files:
                atomic_write_text(path, text)
            entry = files[-1][0]
            compiled = _compile(entry)
    except (ValueError, OSError) as error:
        return Validation(str(error).replace(str(Path(tempfile.gettempdir()).resolve()), "<scratch>"))
    manifest = compiled.manifest
    return Validation(None,
                      tuple(f"{item.name} = {item.value:g} {item.unit}".strip() for item in manifest.unconsumed_parameters),
                      tuple(manifest.unused_roles()))


def save_vehicle(edit: VehicleEdit, directory: Path, stem: str, *, allow_models: bool = False,
                 overwrite: bool = False) -> SavedVehicle:
    """Write the copies as one validated directory transaction.

    Render and compile in a sibling temporary directory. Move the complete set only
    after validation. If any replacement fails, attempt to restore every pre-existing target and
    remove every newly moved file before raising the original error. Cleanup is
    best effort. A failed restore leaves its backup artifact in the staging
    directory until cleanup; abrupt termination or power loss is outside the guarantee.
    Raise ``SaveRefused`` for a safety rule and ``ValueError`` for a bad vehicle.
    """
    directory = Path(directory).expanduser().resolve()
    problem = protected_directory_problem(directory, allow_models=allow_models)
    if problem:
        raise SaveRefused(problem)
    check_name(stem, "file name")
    # Stage beside the destination parent. Do not create the destination until
    # validation succeeds, so a rejected save leaves no empty output folder.
    directory.parent.mkdir(parents=True, exist_ok=True)
    stage = Path(tempfile.mkdtemp(prefix=f".{stem}.", dir=directory.parent))
    backup = stage / ".backup"
    try:
        staged = render_files(edit, stage, stem)
        entry = staged[-1][0]
        # render_files returns a formulation entry for the accepted formulation
        # input. Bare assemblies are rejected by VehicleEdit.open.
        for path, text in staged:
            atomic_write_text(path, text)
        compiled = _compile(entry)
        validation = Validation(
            None,
            tuple(f"{item.name} = {item.value:g} {item.unit}".strip()
                  for item in compiled.manifest.unconsumed_parameters),
            tuple(compiled.manifest.unused_roles()),
        )
        final = [directory / path.relative_to(stage) for path, _ in staged]
        # Include stale files from an earlier save with this stem, so a
        # successful save does not leave orphaned old variants.
        stale = set(directory.glob(f"{stem}__*.xml")) - set(final)
        existing = [path for path in [*final, *sorted(stale)] if path.exists()]
        if existing and not overwrite:
            raise SaveRefused(f"{existing[0]} already exists. Change the file name, or confirm the overwrite")
        backup.mkdir()
        moved: list[Path] = []
        backed_up: list[tuple[Path, Path]] = []
        try:
            for target in existing:
                saved = backup / target.name
                os.replace(target, saved)
                backed_up.append((target, saved))
            for source, target in zip((path for path, _ in staged), final):
                target.parent.mkdir(parents=True, exist_ok=True)
                os.replace(source, target)
                moved.append(target)
        except Exception as original_error:
            # Roll back each item independently. Keep the staging directory if
            # any cleanup fails, so an unrestored backup remains recoverable.
            rollback_errors = []
            for target in moved:
                try:
                    target.unlink(missing_ok=True)
                except Exception as cleanup_error:
                    rollback_errors.append(cleanup_error)
            for target, saved in reversed(backed_up):
                try:
                    os.replace(saved, target)
                except Exception as cleanup_error:
                    rollback_errors.append(cleanup_error)
            if rollback_errors:
                original_error.add_note(f"rollback incomplete; recover backups from {stage}")
                retain_stage = True
            raise original_error
        return SavedVehicle(final[-1], tuple(final), validation)
    except (ValueError, OSError) as error:
        if isinstance(error, SaveRefused):
            raise
        raise ValueError(str(error)) from error
    finally:
        if not locals().get("retain_stage", False):
            shutil.rmtree(stage, ignore_errors=True)


def save_component(source: Path, values: dict[str, float], directory: Path, stem: str, model_id: str, *,
                   allow_models: bool = False, overwrite: bool = False) -> Path:
    """Save one component as a new file with edited parameters and a new id."""
    source, directory = Path(source).resolve(), Path(directory).expanduser()
    check_name(stem, "file name")
    problem = protected_directory_problem(directory, allow_models=allow_models)
    if problem:
        raise SaveRefused(problem)
    target = directory / f"{stem}.xml"
    if target.exists() and not overwrite:
        raise SaveRefused(f"{target} already exists. Change the file name, or confirm the overwrite")
    text = source.read_text(encoding="utf-8")
    if _GENERATED.search(text) and values:
        raise ValueError(f"{source.name} is generated; change the inputs of its tool instead")
    text = xmltext.reanchor(text, source.parent, directory)
    text = xmltext.set_model_id(text, model_id)
    if values:
        text = xmltext.set_parameters(text, values)
    text = _mark_copy(text, source)
    from simplified_vehicle_models.xml.loader import load_model
    with tempfile.TemporaryDirectory() as folder:
        probe = Path(folder) / "probe.xml"
        atomic_write_text(probe, xmltext.reanchor(text, directory, Path(folder)))
        load_model(probe)
    atomic_write_text(target, text)
    return target
```

```python
"""The parameter table of one slot."""
from __future__ import annotations

from PyQt6.QtCore import QAbstractTableModel, QModelIndex, Qt, pyqtSignal
from PyQt6.QtGui import QColor

from tools.vehicle_gui.model import ParameterRow

HEADERS = ("Name", "Value", "Unit", "File value")


class ParameterTableModel(QAbstractTableModel):
    """Rows of one slot. ``edited(name, value)`` fires for a valid number; bad text is refused."""

    edited = pyqtSignal(str, float)
    refused = pyqtSignal(str)

    def __init__(self, parent=None) -> None:
        super().__init__(parent)
        self._rows: list[ParameterRow] = []
        self.locked_reason: str | None = None

    def set_rows(self, rows: list[ParameterRow], locked_reason: str | None = None) -> None:
        self.beginResetModel()
        self._rows, self.locked_reason = list(rows), locked_reason
        self.endResetModel()

    def rowCount(self, parent=QModelIndex()) -> int:
        return 0 if parent.isValid() else len(self._rows)

    def columnCount(self, parent=QModelIndex()) -> int:
        return 0 if parent.isValid() else len(HEADERS)

    def headerData(self, section, orientation, role=Qt.ItemDataRole.DisplayRole):
        if role == Qt.ItemDataRole.DisplayRole and orientation == Qt.Orientation.Horizontal:
            return HEADERS[section]
        return None

    def flags(self, index):
        flags = Qt.ItemFlag.ItemIsSelectable | Qt.ItemFlag.ItemIsEnabled
        if index.column() == 1 and self.locked_reason is None and self._rows[index.row()].numeric:
            flags |= Qt.ItemFlag.ItemIsEditable
        return flags

    def data(self, index, role=Qt.ItemDataRole.DisplayRole):
        row = self._rows[index.row()]
        if role in (Qt.ItemDataRole.DisplayRole, Qt.ItemDataRole.EditRole):
            return (row.name, row.value_text, row.unit, row.original)[index.column()]
        if role == Qt.ItemDataRole.BackgroundRole and row.edited is not None:
            return QColor(255, 244, 200)
        if role == Qt.ItemDataRole.ToolTipRole and self.locked_reason:
            return self.locked_reason
        return None

    def setData(self, index, value, role=Qt.ItemDataRole.EditRole) -> bool:
        if role != Qt.ItemDataRole.EditRole or index.column() != 1:
            return False
        row = self._rows[index.row()]
        try:
            number = float(str(value).strip())
        except ValueError:
            self.refused.emit(f"{row.name}: {value!r} is not a number")
            return False
        if number != number or number in (float("inf"), float("-inf")):
            self.refused.emit(f"{row.name}: the value must be finite")
            return False
        self.edited.emit(row.name, number)
        return True
```

```python
    def _refresh(self) -> None:
        """Redraw the slot, the tree marks and the compiler checks."""
        if self.edit is None:
            return
        for key, item in self._items.items():
            marks = []
            if key in self.edit.edited_keys():
                marks.append("edited")
            if key in save.diverging_keys(self.edit):
                marks.append("swapped")
            item.setText(1, self.edit.file(key).name)
            item.setText(2, ", ".join(marks))
        self._show_slot()
        verdict = save.check_files(self.edit)
        if verdict.ok:
            self.verdict.setText("The vehicle compiles." + ("" if self.edit.changed else " (no changes)"))
            self.verdict.setStyleSheet("color: #1b6e2d")
            lines = []
            if verdict.unconsumed:
                lines.append("Parameters the chosen model does not read:")
                lines += [f"  {text}" for text in verdict.unconsumed]
            if verdict.unused_roles:
                lines.append("Slots the chosen model does not use: " + ", ".join(verdict.unused_roles))
            self.checks.setPlainText("\n".join(lines) or "Nothing is unused.")
        else:
            self.verdict.setText("The vehicle does not compile: " + verdict.error)
            self.verdict.setStyleSheet("color: #b00020")
            self.checks.setPlainText(verdict.error)

    # -- editing ----------------------------------------------------------------------------
    def _edited(self, name: str, value: float) -> None:

        self._refresh()

    def _swap(self) -> None:

            return
        try:
            self.edit = self.edit.with_choice(self.key, Path(path))
        except ValueError as error:

            return

        for key, item in self._items.items():

        self._refresh()

            return
        edit = self.edit
        for row in edit.rows(self.key):
            edit = edit.without_parameter(self.key, row.name)
        self.edit = edit
        self._refresh()

            QMessageBox.warning(self, "Not saved", f"{refusal}")
            return
        except ValueError as error:
            QMessageBox.warning(self, "Not saved", str(error))
            return
        self.statusBar().showMessage(f"saved {saved.entry}", 10000)

    def save_component(self, *, model_id: str | None = None) -> None:
        if self.edit is None or self.key == ASSEMBLY and self.edit.generator(ASSEMBLY):
            return
        from PyQt6.QtWidgets import QInputDialog
        if model_id is None:
            model_id, accepted = QInputDialog.getText(self, "New component", "Model id of the new component:",
                                                      text=f"{self.edit.file(self.key).stem.replace('_', '-')}-copy")
            if not accepted:
                return
        values = dict(self.edit.parameters.get(self.key, {}))

            QMessageBox.warning(self, "Not saved", str(error))
            return

            if answer != QMessageBox.StandardButton.Yes:
                event.ignore()
                return
        self.settings.setValue("geometry", self.saveGeometry())
```

````markdown
# Vehicle GUI

The vehicle GUI changes the parameters of a vehicle model and swaps its components. It always saves new files. It does not change the original files. It checks the result with the real compiler before it writes anything.

## Install

Install the GUI extra from the repository root:

```bash
python -m pip install -e '.[gui]'
```

## Start the GUI

Start the application from the repository root. The optional argument is a vehicle-formulation file:

```bash
PYTHONPATH=src:. python3 tools/vehicle_gui/app.py
PYTHONPATH=src:. python3 tools/vehicle_gui/app.py models/formulations/iem24_murphy_real_planar_7dof.xml
```

## Open a vehicle

Select **Open…** and choose a `vehicle-formulation` file. Bare `vehicle-assembly` files are rejected because they do not identify a formulation subtype. The left tree shows one row for each slot, at any depth, such as `powertrain/power-plant`. The tree uses the same slots as the simulation GUI. The third column marks a slot as `edited` or `swapped`.

## Edit parameters

Select a slot. The table lists the parameters of its file. Double-click a **Value** cell and type a number. The unit column cannot be edited. A value that is not a finite number is refused with a message in the status bar. If you type the value that the file already has, the edit is removed.

The text of the file is changed in place. The comments, the spacing and the order of the lines stay as they are. The **File value** column keeps the original value.

The panel **Checks (the real compiler)** compiles the changed vehicle after each edit. It shows the verdict, the parameters that no model consumes and the roles that no component uses. A value that the compiler rejects, for example a `unit_count` that is not a whole number, turns the verdict red. A save of such a vehicle writes no file and shows the reason.

## Swap a component

Select a slot. The list shows the registered components that fit the slot. The rule is the one of the simulation GUI. Select a component and **Use this component**. **Revert slot** undoes the edits and the swap of the slot.

## Generated slots are locked

Some component files carry the comment `Generated by tools/...` (suspension layouts, springs, anti-roll bars, kinematics, dampers and hydraulics). Their values come from a generator. The GUI shows them as read-only and names the tool. You can still swap such a slot for another component. To change a value, change the input of the generator and run it again.

## Save

The save bar has a folder, a file name and two switches. The default folder is `vehicles_out/` in the repository root. Git ignores it. A save replaces all files for the chosen stem and removes stale `<stem>__*.xml` outputs from earlier saves in the same folder. It stages and validates the complete set first. A normal in-process replacement failure restores the prior set. If rollback itself fails, cleanup continues, the original error remains raised, and the staging/backup directory is retained with a recovery-path note; an affected target may be missing until recovery. Abrupt termination or power loss during commit is outside the guarantee.

**Save as new vehicle** writes these files:

| File | Content |
|---|---|
| `<name>__formulation.xml` | The formulation. Open this file in the simulation GUI. |
| `<name>__vehicle.xml` | The assembly, when it or a component below it changed. |
| `<name>__<slot>.xml` | One file for each edited slot and for each parent of an edited or swapped slot. A slot path uses `__` for `/`. |

Files that did not change are referenced and not copied. Each copied model gets the id suffix `.<name>`. Each copy has a line `Saved by tools/vehicle_gui from <original>` after the XML declaration. A copy of a generated file does not claim to be generated: its `Generated by` comment becomes `Derived from output of`.

**Save this slot as a new component…** asks for a model id and writes one file `<name>.xml`. A generated slot cannot be saved with changed values.

The GUI applies these rules:
- Open accepts a `vehicle-formulation` only. A bare `vehicle-assembly` is rejected because its formulation subtype is unknown.

- A folder inside `models/` is refused unless you tick **Allow writing inside models/**.
- An existing file is refused unless you tick **Overwrite existing files**.
- If the compiler rejects the vehicle, the GUI writes no file.
- The file name has 1 to 40 letters, numbers, `_` or `-`.
````
