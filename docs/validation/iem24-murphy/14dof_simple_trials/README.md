# 14dof_simple_trials

Forward-driver attempts of the vertical 14-DoF model on the endurance lap.

## Subdirectories

| Directory | Purpose |
|---|---|
| `periodicity/` | Attempts that check the periodicity of the 14-DoF lap. |
| `refinement/` | Attempts that check the 14-DoF lap at a refined step. |

## Attempt directories

Holds 4 `attempt_<timestamp>/` directories. Each one is a single recorded solver attempt. Heavy traces and logs inside them are not tracked by git.
