## Failed tube attempts (kept on purpose)

The tube criterion needs every state component's sup difference to shrink from the coarse-medium pair to the medium-fine pair. Two triples failed and were not used:

- `seven_dof/tube_refined_finer_fourth_FAILED.json`: refined/finer/fourth. The 7DoF tube was instead evaluated on warm/refined/finer, where every component shrinks, and the certificate is attached to the `finer` attempt.
- `vertical_14dof/tube_warm_refined_finer_FAILED.json`: warm/refined/finer. Eleven components did not shrink (for example `state_13`, the front-right wheel speed, grew from 3.0e-3 to 8.8e-3 rad/s). A `fourth` stage was run and refined/finer/fourth shrinks in every component, so the 14DoF tube uses that triple.

Choosing the triple after seeing the result is a judgement call; the failed triples are recorded so it is visible. No threshold was relaxed.

## Scope: what `usable = true` means

- It is numerical acceptance: the lap closes periodically, tracks the path within 0.25 m, is reproduced by tighter-step and tighter-tolerance reruns, and satisfies the between-step checks. It is not validation against measured data.
- The 7DoF between-step certificate includes an interval load-closure certificate.
- The 14DoF certificate (`solvers/vertical_between_step.py`, `SCOPE`) proves only evaluation-domain guards by interval arithmetic on the BDF dense enclosure: jounce spline domain, damper velocity axis, tire inverse domain, load cap, mass-block eigenvalue, speed, wheel speed, SOC and steering headroom. Wheel lift (`wheel_lift_possible`) is recorded as a diagnostic only, not as a pass/fail check; it is false for this artifact. It does not enclose the powertrain `brentq` closure (covered by `tests.test_powertrain_closure_audit`), the transient-tire forces, or the true ODE trajectory. The enclosure bounds the BDF interpolant, and rounding is handled by padding, not directed rounding.
- The refinement tube is empirical, from three refinement levels under an assumed geometric convergence.
