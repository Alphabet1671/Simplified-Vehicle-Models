# forward-usability-sweep

Attempts of the forward-driver usability sweep, grouped by model setup.

## Subdirectories

| Directory | Purpose |
|---|---|
| `planar/` | Sweep attempts of the planar model. |
| `planar_canonical/` | Sweep attempts of the canonical planar setup. |
| `planar_canonical_b/` | Sweep attempts of the second canonical planar setup. |
| `vertical_canonical/` | Sweep attempts of the canonical vertical setup. |
