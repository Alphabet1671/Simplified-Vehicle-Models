## Files

| File | Contents |
|---|---|
| `mesh_sensitivity_summary.csv` | CSV table. |

| Directory | Purpose |

| `spacing_1/` | Run at 1 m mesh spacing. |
| `spacing_2/` | Run at 2 m mesh spacing. |
