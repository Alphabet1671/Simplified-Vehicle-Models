# seven_dof_track_pair

7-DoF forward-driver laps on two tracks, one subdirectory per track, with the comparison outputs.

## Files

| File | Contents |
|---|---|
| `canonical_comparison.csv` | CSV table. |
| `comparison.png` | Figure. |
| `comparison_summary.json` | JSON record. |
| `lap_spread.png` | Figure. |
| `original_comparison.csv` | CSV table. |
| `simulated_lap.png` | Figure. |
| `three_overlay.png` | Figure. |
| `tube_v2_protocol.freeze.txt` | Text file. |
| `tube_v2_protocol.md` | Markdown file. |

## Subdirectories

| Directory | Purpose |
|---|---|
| `new/` | Acceptance runs of the 7-DoF model on the new track. |
| `original/` | Acceptance runs of the 7-DoF model on the original track. |
