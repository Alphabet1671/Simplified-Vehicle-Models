# models

XML model graph: one subdirectory per model type.

## Subdirectories

| Directory | Purpose |
|---|---|
| `aero/` | Aerodynamic models. |
| `anti-roll-bars/` | Anti-roll bar models. |
| `controllers/` | Driver and drivetrain controller models. |
| `dampers/` | Damper models. |
| `data/` | Lookup tables referenced by the models (CSV and NPZ). |
| `drivetrains/` | Drivetrain models. |
| `energy-storages/` | Battery and energy-storage models. |
| `formulations/` | Formulations: a formulation picks the vehicle model that the compiler resolves. |
| `hydraulics/` | Hydraulic circuit models. |
| `power-plants/` | Electric motor models. |
| `powertrains/` | Powertrain assemblies. |
| `springs/` | Spring models. |
| `suspension-kinematics/` | Suspension kinematics models. |
| `suspensions/` | Suspension models. |
| `tires/` | Tire models. |
| `tracks/` | Track models and their data tables. |
| `transmissions/` | Transmission models. |
| `vehicles/` | Vehicle assemblies. |
