# drivetrain

Drivetrain component code.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Package marker. |
| `controller.py` | Pedal-input interpretation owned by the drivetrain controller model. |
| `fixed_split.py` | Allocate a drive and a brake demand to four wheel torques. |
| `lumped.py` | Compile the lumped four-wheel-electric drivetrain component. |
| `transmission.py` | Compile and evaluate an independent fixed-ratio transmission. |
