# hydraulics

Hydraulic circuit elements and solver.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Hydraulic circuit elements and the interconnected-suspension circuit solver. |
| `circuit.py` | Quasi-static hydraulic circuit with gas accumulators at every junction. |
| `elements.py` | Hydraulic elements: orifices and polytropic gas accumulators (NumPy only). |
| `table.py` | Loader of the ``hydraulic-circuit-v1`` NPZ (sha256 pinned). |
