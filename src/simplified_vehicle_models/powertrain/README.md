# powertrain

Electric powertrain components.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Provide electric powertrain components. |
| `assembly.py` | Compose the electric powertrain and drivetrain assemblies. |
| `energy_storage.py` | Model a battery pack from exported cell curves. |
| `motor_envelope.py` | Compile and evaluate a smooth motor torque, speed, and power envelope. |
| `power_plant.py` | Model a voltage-dependent electric motor. |
| `wheel_drive.py` | Bound the drive torque of each wheel by the motor and the battery. |
