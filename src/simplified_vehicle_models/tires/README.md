# tires

Tire component code.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Package marker. |
| `friction_ellipse.py` | Compile the load-sensitive friction-ellipse tire component. |
| `unitire_envelope.py` | Reduce simplified UniTire to a pure-force lookup for point-mass use. |
| `unitire_simple.py` | Evaluate the fitted simplified steady-state UniTire model. |
| `unitire_transient.py` | Provisional transient layer around the unchanged steady UniTire function. |
| `vertical.py` | Tire vertical load from wheel deflection. |
