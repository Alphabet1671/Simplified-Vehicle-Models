# tracks

Track geometry code.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Package marker. |
| `boundary_view.py` | Explicit full-course topology views for boundary-condition experiments. |
| `corridor.py` | Express track edges as a fold-guarded lateral corridor. |
| `geometry_audit.py` | Sampled, diagnostic-only comparison of loaded track and fitted geometry. |
| `line_trajectory.py` | Analytic offset trajectories derived from a differentiable XY reference. |
| `offset_spline.py` | Cubic offset basis with periodic and open boundary operators. |
| `path_coordinates.py` | Evaluate one signed path at a progress distance. |
| `periodic_cut.py` | Immutable exact station mapping and sampled views for periodic source fits. |
| `profile.py` | Python module `profile`. |
| `racing_line.py` | Reconstruct signed paths from lateral offsets. |
| `types.py` | Python module `types`. |
