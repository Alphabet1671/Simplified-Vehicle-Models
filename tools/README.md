# tools

Runnable programs: studies, report generators, data import/export and GUIs. Programs only, no documentation.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Package marker. |

## Subdirectories

| Directory | Purpose |
|---|---|
| `anim/` | Animation export from a run record to video. |
| `anim_gui/` | Animation GUI. |
| `data/` | Telemetry and spec-sheet import. |
| `diagnostics/` | Diagnostic and profiling scripts. |
| `gates/` | Acceptance-gate checkers. |
| `gui_common/` | Code shared by the GUIs. |
| `maneuver_gui/` | Simulation-only maneuver execution and its Qt widgets. |
| `model_data/` | Generators and exporters for the files in `models/`. |
| `reports/` | Report generators and plot scripts. |
| `run/` | Run scripts for solver attempts and sweeps. |
| `sim_gui/` | Simulation GUI. |
| `tire_gui/` | Tire correlation GUI. |
| `track_gui/` | Track GUI. |
| `tracks/` | Track builders. |
| `vehicle_gui/` | Vehicle GUI. |
