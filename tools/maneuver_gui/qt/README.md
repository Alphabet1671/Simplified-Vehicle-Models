# qt

Qt layer of the maneuver tools.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Qt widgets for editing and previewing simulation maneuvers. |
| `controller.py` | Qt lifecycle wrapper for simulation-only maneuver execution and canonical result handoff; no video rendering. |
| `csv_dialog.py` | Strict CSV playback import and mapping dialog. |
| `editor.py` | Qt adapter binding editable controls to the maneuver draft. |
| `preview.py` | Aligned requested/applied command trace preview. |
| `tab.py` | Simulation-only maneuver tab with lap-style run controls. |
