# run

Run scripts for solver attempts and sweeps.

`run_forward_acceptance_chain.sh MODEL OUT PREVIEW HEADING LATERAL` runs a cold seed then a warm flying lap by default. Append `both --track TRACK.xml` for an explicit track, and set `PYTHON=.venv/bin/python` to select the environment. A warm lap must match the seed's actual source hashes and controller/policy identity; changed code requires a fresh cold seed.

`--physical-brake-planning` selects the opt-in versioned `physical-reachable-v1` operational brake forecast. It uses current-state plant context and retains the policy's actual transition timing; the separate 3 s value is forecast horizon metadata, not a foot-transition setting. Outcomes remain sampled/model-conditioned diagnostics, not a feasibility certificate or tire-authority guarantee. Historical preview is the default; `--longitudinal-mode legacy` explicitly selects the newer braking-envelope policy. This option may be combined with `--transient-corner-planning`, which enables the sampled yaw-transition axle-force screen plus the first-order steering-actuator inverse feedforward. Both flags and their source/configuration identities bind into warm starts.

The isolated driver also accepts opt-in `--longitudinal-mode hybrid-drive-brake-v1` on `14dof-simple`; it requires an explicit positive `--initial-speed` rolling start (default remains 0 m/s for other modes; standing-rest hybrid starts are unqualified). Hybrid mode binds its initial speed and verified-relay policy limits (up to 8 extra complete forecasts, 1e-8 normalized first-target bracket resolution, at most 11 forecasts and 11×configured slabs attempted transitions) into canonical setup and warm-start identity. The shared hybrid setup remains 30 slabs over 3 s; API policy default remains 60 slabs. The isolated driver accepts `--vertical-corner-samples N` (default 0) on `14dof-simple` only. `N` bounds total offline steady-corner queries. Results are sparse tested-speed restrictions, not physical maxima or a full-track feasibility guarantee. The existing lateral margin remains in force. Both models accept an explicitly selected positive parent timeout; the default remains 300 seconds.
