# qt

Qt layer of the track GUI.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Package marker. |
| `main_window.py` | The track GUI main window: a design tab and a closed-track tab. |
| `plots.py` | Two plain QPainter plots: the course in the XY plane and curvature against distance. |
| `section_table.py` | The editable section table. |
| `track_viewer.py` | Existing track viewer with safe reverse and closed-section export. |
