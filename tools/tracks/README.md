# tracks

Track builders.

## Files

| File | Contents |
|---|---|
| `__init__.py` | Package marker. |
| `build_closed_track.py` | Build one closed signed XY track from a measured velocity trace. |
| `build_fsae_dynamic_tracks.py` | Build the Formula SAE acceleration and skidpad track models. |
| `build_iem24_multilap_track.py` | Build a *separate* representative racing-line geometry from measured flying laps. |
| `build_width_profile.py` | Write a lateral corridor table for a track. |
| `open_course.py` | Build a signed open course from sections of linearly varying curvature. |
